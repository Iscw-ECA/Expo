# Galerie-ISCW-ECA
Ensemble des projets proposés dans le cours de ECA

La convention de nommage des fichiers : Pour que le titre de l'œuvre apparaisse proprement sur le site, voici la convention de nommage à adopter pour vos images et vos sons dans le dossier assets/ :$$\text{Classe}\_\text{Prenom}\_\text{Titre De L'Oeuvre.jpg}$$ Exemples concrets :1Ca_Lucas_Autoportrait Electrique.jpg (+ 1Ca_Lucas_Autoportrait Electrique.mp3)Sur le site : Titre = Autoportrait Electrique, Nom = Lucas.1Ca_Emma.jpg (+ 1Ca_Emma.mp3)Sur le site (si pas de titre dans le fichier) : Titre = Emma, Nom = Emma.

Chaque image jpg doit porter EXACTEMENT (minuscule et Majuscule) le même nom que le MP3.  Eviter les accents.

Le tout doit être importé dans un Dossier (reprenant année scolaire) / projet(num)_nomduprojet (!!!le tout sans Majuscule)/assets (le assets sans majuscule est indispensable) exemple : 2026-2027/projet1_autoportrait/assets

Création des dossiers dans le projet & ADD FILES - CREATE NEW FILES...Les dossiers se créent dés qu'un / est inséré

 Parfois nécessaire d'importer en plusieurs fois.
