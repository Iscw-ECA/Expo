# Galerie-ISCW-ECA
Ensemble des projets proposés dans le cours de ECA

La convention de nommage des fichiersPour que le titre de l'œuvre apparaisse proprement sur le site, voici la convention de nommage à adopter pour vos images et vos sons dans le dossier assets/ :$$\text{Classe}\_\text{Prenom}\_\text{Titre De L'Oeuvre.jpg}$$Exemples concrets :1Ca_Lucas_Autoportrait Electrique.jpg (+ 1Ca_Lucas_Autoportrait Electrique.mp3)Sur le site : Titre = Autoportrait Electrique, Nom = Lucas.1Ca_Emma.jpg (+ 1Ca_Emma.mp3)Sur le site (si pas de titre dans le fichier) : Titre = Emma, Nom = Emma.
